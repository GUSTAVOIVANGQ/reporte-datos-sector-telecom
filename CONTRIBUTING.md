# Contribuir

1. Cree una rama desde la versión estable.
2. No agregue CSV del BIT, credenciales, reportes generados ni cachés.
3. Ejecute las pruebas R y Python indicadas en `README.md`.
4. Actualice `CHANGELOG.md` cuando cambie comportamiento, datos o despliegue.
5. Abra una revisión describiendo el motivo, los periodos probados y cualquier diferencia de cifras.

Los cambios en agregaciones, validaciones o formato Word deben incluir una prueba reproducible. Los
secretos y URL privadas se proporcionan exclusivamente mediante variables de entorno.
